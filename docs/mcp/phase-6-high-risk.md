# 阶段 6：高风险操作开放顺序

阶段 6 在阶段 5 稳定性门禁通过后启动。原则是先开放可止损、可逆、不会新增网络行为的操作，再评估主动执行能力。

## 第一项：紧急停止执行器

候选工具：`wpe_executors_stop_all`

范围：

- 停止当前发送器和机器人执行任务；
- 不启动执行器；
- 不修改发送列表、机器人列表或任务配置；
- 不主动发包；
- 返回停止前后的发送器/机器人运行数量。

强制安全条件：

- 必须提供 UUID 幂等键；
- 必须始终显示 WPE 本机确认；自动批准开关不能绕过确认；
- 确认摘要不得包含任务正文、封包内容、密码或令牌；
- 执行和结果写入脱敏审计日志；
- 重复幂等键返回第一次结果，同键不同参数拒绝；
- 仅在 UI 线程调用已有停止入口；
- 停止失败时返回明确失败结果，不伪造成功。

## 暂不开放

- 主动发包；
- 注入、驱动和进程控制；
- 启动执行器；
- 自动修改滤镜或发送任务；
- 密码、令牌和完整 Payload 读取。

## 开放前测试

1. 无运行任务时幂等成功，运行数为 0；
2. 有发送器/机器人时确认后全部停止；
3. 拒绝确认不改变运行状态；
4. 自动批准开关开启时仍必须确认；
5. 重复幂等键不重复执行；
6. 同键不同参数拒绝；
7. WPE 重启后没有残留执行器状态；
8. Sidecar 工具描述、Schema、审计和错误结果全部同步。
