# 阶段 6：高风险操作开放顺序

阶段 6 在阶段 5 稳定性门禁通过后启动。原则是先开放可止损、可逆、不会新增网络行为的操作，再评估主动执行能力。

## 第一项：紧急停止执行器

候选工具：`wpe_executors_stop_all`

范围：

- 停止当前发送器和机器人执行任务；
- 不启动执行器；
- 不修改发送列表、机器人列表或任务配置；
- 不主动发包；
- 返回停止前后的发送器/机器人运行数量。

强制安全条件：

- 必须提供 UUID 幂等键；
- 遵循 MCP 全局“需要人工确认”开关：默认显示 WPE 本机确认，关闭全局确认后按统一策略直接执行；
- 确认摘要不得包含任务正文、封包内容、密码或令牌；
- 执行和结果写入完整审计日志；
- 重复幂等键返回第一次结果，同键不同参数拒绝；
- 仅在 UI 线程调用已有停止入口；
- 停止失败时返回明确失败结果，不伪造成功。

## 已开放

- `wpe_executors_stop_all`：已接入 MCP 工具、幂等守门、全局确认策略和完整审计；仅调用既有停止入口。

## 暂不开放

- 主动发包；
- 注入、驱动和进程控制；
- 启动执行器；
- 自动修改滤镜或发送任务；
- 任意文件、剪贴板、驱动操作和自动注入。

## 开放前测试

1. 无运行任务时幂等成功，运行数为 0；
2. 有发送器/机器人时确认后全部停止；
3. 拒绝确认不改变运行状态；
4. 全局确认开关开启时必须确认，关闭时按自动执行路径验证；
5. 重复幂等键不重复执行；
6. 同键不同参数拒绝；
7. WPE 重启后没有残留执行器状态；
8. Sidecar 工具描述、Schema、审计和错误结果全部同步。
